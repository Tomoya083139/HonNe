# 参考アプリ解析: Sekirara（セキララ）

対象:
- iOS アプリ「Sekirara-カップル質問ゲーム」(Sekirara Card Inc. / id6476960871)
- 物理カード「セキララカード」公式サイト (sekiraracard.com)

## 1. コンセプト

- 「本音で話すきっかけ」をつくる質問カード。日常で言いづらい感謝・気になっていることをカードが代わりに聞く。
- 物理カード（2023年発売, 約2,000人利用）→ アプリ化。カードを持ち歩かなくても遊べる、が訴求点。
- 使用シーンを明示: デート中 / 記念日 / ドライブ / 旅先 / 待ち時間 / 寝る前 / 電話中(遠距離)。

## 2. UX フロー（アプリ）

```
起動 → デッキ選択(Home) → テーマ選択 → カード画面(スワイプで次へ) → [3枚で有料誘導]
```

- **Home**: デッキ一覧を縦スクロールのカード型ボタンで表示（For Couples / For Friends / For Family / Self-Care / Life-Interview ...）。各デッキに「3枚まで無料」バッジ。
- **カード画面**:
  - 上部ヒント「スワイプすると次のカードにうつるよ」、右上に赤い × (終了)
  - 画面中央に 1 枚のカード。上半分がデッキ色の曲線塗り（波形）、下半分が白。
  - 質問は日本語(太字) + 英語(小文字イタリック系)の 2 言語併記。
  - カード下部にブランドロゴ。
  - ランダム順で出題。パス = そのままスワイプ。
- 極めてシンプル。ログイン・回答記録・履歴・ペアリング機能は無し。

## 3. コンテンツ構造

| デッキ | 対象 | テーマ | 枚数 (アプリ) |
|---|---|---|---|
| For Couples | 恋人・夫婦 | ライト価値観 / ディープ価値観 / ライト恋愛観 / ディープ恋愛観 | 150+ |
| For Friends | 友達 | ライト価値観 / ディープ価値観 / ライト恋愛観 / ディープ恋愛観 | 150+ |
| 親子用 | 親と子 | おうちのこと / 自分のこと / 考えてみよう | 50 |
| 人生インタビュー | 親・祖父母 | 幼いとき / 親になってから / 祖父母になってから | 50 |
| アイスブレイク | 初対面 | 普段の生活 / これまでの思い出 / 性格やこれからのこと | 50 |
| セルフケア | ひとり | 今の自分 / これまでの自分 / これからの自分 | 50 |
| セルフリフレクション | ひとり | じぶん診断 / 心の深掘り / これからの指針 | 50 |
| 失恋 | ひとり | 振り返る / 手放す / 進む | 50 |

設計上のポイント:
- **深さのレベル分け**（物理版は 4 レベル）。軽い質問から始めて徐々に深く → 心理的安全性を担保。
- **テーマ = 「価値観 × 恋愛観」×「ライト × ディープ」** の 2 軸マトリクス。
- 質問は 1 文・短い・オープンクエスチョン（「〜は？」で終わる）。

質問例（公開情報より）:
- 最近、相手に惚れ直したのはいつ？
- 意見が違ったとき、どう対処するのが理想？
- 相手にまだ話したことのない夢は？
- 将来について、実は少し不安に思っていることは？
- あなたにとって、浮気の基準は？相手にされて嫌なことは？
- 今年中に 2 人で一緒にしたいことは？
- きっちりスケジュール派？それとも行き当たりばったり派？
- もし 1 日だけ、おうちの人と入れかわれたら、最初にしたいことは？
- 昔必要だったけど今不要なものは？

## 4. ルール（4つの鉄則）

1. 相手の話を最後まで聞く
2. 普段話せない本音もこの場では自由
3. 話したくないカードはパス OK
4. 「普通はこう」ではなく「私はこう」と自分軸で話す

→ アプリ内には明示されていないが、初回オンボーディングで見せる価値がある。

## 5. ビジネスモデル

- 無料: 各デッキ 3 枚まで
- 買い切り ¥3,000 / デッキ（月額なし）。物理カードは ¥2,980。
- 15 言語対応（日英併記が基本、外国籍パートナーとの利用も想定）
- App Store カテゴリ: ヘルスケア/フィットネス、16+

## 6. レビュー・ユーザーの声から分かる価値

- 長く付き合っていても知らない一面が出てくる
- 遠距離・電話中の会話ネタになる
- 初対面でも深い話ができる
- デザインが可愛い／洗練されている
- ノートに回答を記録して振り返ると効果倍増（記事）

## 7. 参考アプリの弱点 = 「本音」で伸ばせる余地

| 弱点 | 本音での改善案 |
|---|---|
| 質問が 1 種類（オープン質問のみ） | 二択・当てっこ・せーの回答・お願いカード等、質問**形式**を増やす |
| デッキ単位 ¥3,000 は高く、無料 3 枚では体験できない | 無料枠を厚く、コアは無料で継続利用させる |
| 回答が残らない、振り返りできない | 回答メモ・お気に入り・履歴・「◯ヶ月前の2人の答え」 |
| 「話す時間を作る」仕掛けがない | 今日の 1 問通知、5/15/30 分セッション、記念日モード |
| 2 人の関係の変化に追随しない | 付き合い始め / 同棲 / 結婚 / 子育て / 遠距離 などステージ別デッキ |
| 出題がただのランダム | ライト→ディープの自動グラデーション、既出除外、ムード指定 |
