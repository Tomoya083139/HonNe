# 本音（HonNe）設計ドラフト

> 2 人の「話す時間」をつくる質問カードアプリ。Sekirara の基本設計（デッキ → テーマ → スワイプでカード）を踏襲しつつ、質問の量・種類・深さと「時間をつくる仕掛け」で差別化する。

## 1. プロダクト方針

- **主役は 2 人**（恋人・夫婦）。友達・家族・ひとり用は拡張デッキとして後続。
- **オフライン完結 / ログイン不要** で MVP。ペア同期などオンライン機能は Phase 3。
- **コンテンツは JSON データ駆動**。質問の追加・翻訳・レベル調整をコードを触らずに行える。
- 日本語ファースト、英語併記（Sekirara 同様、外国籍パートナー対応）。

## 2. 機能一覧（優先度順）

### Phase 1 – MVP（Sekirara 相当 + α）
- デッキ選択 → テーマ / 深さレベル選択 → カードスワイプ画面
- パス（左スワイプ）/ 次へ（右スワイプ）/ お気に入り（長押し or ボタン）
- 既出カードの除外、シャッフル、リセット
- **セッション設定**: 枚数（5/10/20/∞）、深さ（ライト→ディープの自動グラデーション）
- **ターン表示**: 「◯◯の番」を交互に表示（名前は初回に登録、ローカル保存）
- オンボーディング（4 つの鉄則）
- 日英併記、ダークモード

### Phase 2 – 質問の拡張（本アプリの核）
- 質問**形式**の追加（§4）
- デッキ・テーマの追加（§3）、目標 **600 問以上**
- 回答メモ（2 人分）・履歴・「あのとき 2 人はこう答えた」振り返り
- ムード指定（盛り上がりたい / しっとり / ケンカ後 / 記念日）

### Phase 3 – 「時間をつくる」仕掛け
- 今日の 1 問（プッシュ通知、時刻設定）
- 記念日・付き合った日数カウンター → 記念日限定カード
- 5 / 15 / 30 分タイマーセッション
- ペア連携（QR で結合）: 遠距離向けに同じカードを同期、相手の回答を「せーの」で公開

### Phase 4 – 収益化・多言語
- 基本デッキ無料、拡張デッキ買い切り or 月額、広告なし
- 多言語（韓・中・英以外）

## 3. コンテンツ設計

### 3.1 デッキ（対象別）

| deck id | 名称 | 説明 |
|---|---|---|
| `couple` | 恋人と | 基本デッキ。Sekirara Couples を拡張 |
| `married` | 夫婦・パートナーと | 家事・お金・将来・親族・子育て |
| `long_distance` | 遠距離で | 電話・ビデオ通話前提の質問 |
| `first_date` | はじめての 2 人 | 付き合い始め・初デート向けアイスブレイク |
| `anniversary` | 記念日に | 振り返り・感謝・これから |
| `after_fight` | すれ違ったあとに | 仲直り・気持ちの言語化（慎重に設計） |
| `friends` | 友達と | 後続 |
| `family` | 家族と | 後続 |
| `self` | ひとりで | 後続 |

### 3.2 テーマ（横断）

`values` 価値観 / `love` 恋愛観 / `past` 過去・思い出 / `future` 将来 / `daily` 日常・生活 / `money` お金・仕事 / `family` 家族・親族 / `body` 身体・健康・親密さ(16+) / `feelings` いまの気持ち / `gratitude` 感謝 / `fun` ネタ・妄想

### 3.3 深さレベル

| level | 名称 | 例 |
|---|---|---|
| 1 | ライト | きっちりスケジュール派？行き当たりばったり派？ |
| 2 | ミディアム | 最近、相手に惚れ直した瞬間は？ |
| 3 | ディープ | 将来について、実は少し不安に思っていることは？ |
| 4 | セキララ | あなたにとって浮気の基準は？ |

セッションは level 1 → 4 へ自動的に上げていく（例: 10 枚なら 3/3/2/2）。

## 4. 質問形式（Sekirara にない拡張）

| type | 形式 | UI |
|---|---|---|
| `open` | オープン質問（既存型） | 質問文のみ |
| `choice` | 二択・三択（「AとBどっち派？」） | 選択肢ボタン。2 人が選んで一致/不一致を表示 |
| `guess` | 当てっこ（「相手の好きな食べ物を当てて」） | 出題→相手が正解を言う→◯✕ |
| `reveal` | せーの（両方が答えを書いてから同時公開） | 各自入力 → 「せーの」ボタンで同時表示 |
| `scale` | 10 点満点（「今の幸福度は？」） | スライダー 2 本 |
| `thanks` | 感謝・言葉を贈る（「最近ありがとうと思ったこと」） | 相手に向けて読み上げる導線 |
| `wish` | お願い・約束（「来月までに 2 人でしたいこと」） | 回答をリマインダーとして保存可 |
| `action` | ちょいミッション（「30 秒ハグ」「今の気持ちを一言で」） | タイマー付き |

## 5. データモデル

```jsonc
// content/decks/couple.json
{
  "id": "couple",
  "name": { "ja": "恋人と", "en": "For Couples" },
  "color": "#F4A27C",
  "themes": ["values", "love", "past", "future", "daily", "fun"],
  "cards": [
    {
      "id": "couple_0001",
      "type": "open",
      "level": 2,
      "themes": ["love"],
      "text": {
        "ja": "最近、相手に惚れ直した瞬間は？",
        "en": "When did you recently fall for your partner all over again?"
      },
      "tags": ["date", "anniversary"],
      "rating": "all"          // all | 16+
    },
    {
      "id": "couple_0002",
      "type": "choice",
      "level": 1,
      "themes": ["daily"],
      "text": { "ja": "旅行はきっちり計画派？ゆるゆる派？", "en": "..." },
      "options": [
        { "ja": "きっちり計画", "en": "Plan everything" },
        { "ja": "ゆるゆる", "en": "Go with the flow" }
      ]
    }
  ]
}
```

ローカル保存（端末内 DB）:
- `profile`: 2 人の名前、記念日、言語
- `progress`: デッキごとの既出カード ID
- `favorites`: カード ID
- `answers`: `{cardId, date, answers: {A: "...", B: "..."}}`
- `sessions`: 日時・デッキ・枚数（振り返り用）

## 6. 画面構成

```
Onboarding(初回のみ) ─┐
                       ▼
Home ── デッキ一覧（カード型ボタン + 今日の1問 + 記念日カウンター）
  │
  ├─ DeckDetail ── テーマ / 深さ / 枚数 / ムード を選ぶ → 「はじめる」
  │      │
  │      ▼
  │   Session ── カード（スワイプ） / ターン表示 / パス / ♥ / メモ
  │      │
  │      ▼
  │   SessionSummary ── 今日話した枚数・お気に入り・メモ → Home
  │
  ├─ Library ── お気に入り / 履歴 / 回答の振り返り
  └─ Settings ── 名前 / 記念日 / 通知 / 言語 / テーマ色
```

カードのビジュアルは Sekirara を踏襲: 上半分にデッキ色の曲線、下半分に白、日本語太字 + 英語小さめ、下部にロゴ「本音」。

## 7. 技術スタック候補

| 選択肢 | 長所 | 短所 |
|---|---|---|
| **Expo (React Native + TypeScript)** | Windows で開発可、EAS Build で Mac なしに iOS ビルド可、iOS/Android 同時、Reanimated でスワイプが容易 | ネイティブ感は Flutter と同等程度 |
| Flutter | 高品質アニメーション、単一コードベース | iOS ビルドに Mac 必須 |
| SwiftUI | iOS ネイティブ最高品質 | iOS のみ、Mac 必須、Android 不可 |
| PWA (Web) | ストア不要、即公開 | 通知・IAP が弱い、"アプリ感" が薄い |

推奨: **Expo + TypeScript + expo-router + react-native-reanimated + SQLite (expo-sqlite)**。
理由: 開発環境が Windows であること、ストア配信を見据えつつ Mac 無しで iOS ビルドまで到達できること。
